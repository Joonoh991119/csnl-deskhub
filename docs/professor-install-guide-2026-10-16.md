# 교수님 맥 DeskHub 설치 안내 (2026-10-16, 0.37.0 · 기본 화면 = 랩 허브)

랩장 지시(2026-10-16): 리뷰 2차 투표(안내판 2 · 랩 허브 2 → 랩장 표 우선)로 **랩 허브**를 기본 화면으로 교수님(SL) 맥에 설치한다. 설치는 랩장(박준오)이 직접 해 드린다. 교수님께는 **실제로 동작하는 것과 예시로 만들어 둔 것을 구분해** 설명드린다(사용 안내: `manual/professor-manual-2026-10-16.html`).

## 1. 준비물 (랩장이 직접)
- 연구실 공용 저장소 연결: Finder → 이동 → 서버에 연결 → `smb://147.47.70.15/CSNL_new` (로그인 뒤 자동 연결로 두면 재부팅 뒤에도 붙음).
- 배포본 버전 확인: `cat /Volumes/CSNL_new/Grant/_ssot/deskhub/latest.json` 의 `"version"` 이 `0.37.0` 인지 본다(아니면 배포를 기다린다).
- 캘린더: macOS 캘린더에 연구실 구글 계정을 연결하고 권한 요청 창에서 허용. DeskHub 에는 **CSNL Calendar · SLab Calendar 두 개만** 보인다(개인 캘린더는 섞이지 않음).

## 2. 설치 (터미널) — 0.36.0 R3 부터 범용 빌드라 Intel·Apple 칩 모두 된다(`uname -m` 으로 확인 가능)
```
zsh /Volumes/CSNL_new/Grant/_ssot/deskhub/update.sh --force        # 공용 저장소 배포본 설치·실행
zsh /Volumes/CSNL_new/Grant/_ssot/deskhub/setup_env.sh SL           # Notion 연결 열쇠·이니셜 저장 후 앱을 다시 켬
pkill -x DeskHub                                                    # 기본 화면을 정하기 위해 잠시 종료
defaults write kr.ac.snu.csnl.deskhub DeskHub.viewMode hub          # 기본 화면 = 랩 허브 (코드 기본값도 랩 허브라 확인용)
defaults read kr.ac.snu.csnl.deskhub DeskHub.viewMode               # → hub 가 나오면 됨
open -a DeskHub
```
- `setup_env.sh` 는 연결 열쇠를 **화면에 보이지 않게** 물어본다. 열쇠는 랩장이 직접 입력하고 메신저·메일로 보내지 않는다. 이니셜 자리에는 교수님 이니셜 `SL`.
- 처음 실행하면 이니셜 확인 줄이 뜬다: "이 맥에 저장된 이니셜은 SL 입니다. 본인이 맞으면 SL 를, 아니면 본인 이니셜을 눌러 주세요 (이 맥에만 저장)" → `SL` 한 번 클릭.
- 기본 화면은 이 맥에 저장되며 숫자 키 1~4 로 언제든 바꿀 수 있다(1 관제탑 · 2 공정 보드 · 3 안내판 · 4 랩 허브).
- 숨기기·꺼내기: ⌃⌥D. 새 버전이 배포되면 메뉴 막대 DeskHub 아이콘 오른쪽 클릭 메뉴에 '새 버전 받기' 가 생긴다(새 버전이 없으면 안 보임).

## 3. 화면 설명 (0.37.0)
- 랩 허브는 카드마다 **가까운 것만** 보인다: 일정 오늘·내일, 리마인더·그랜트 마감 7일 안, 학회 초록 마감 2주 안·개최 한 달 안, 회의록 1건, Paper Blitz 3편, 최신 원고 한 달 안 2편. 나머지는 카드 아래 '▸ 더 보기' 로 제자리에서 펼치고 '▾ 접기' 로 접는다(이 맥에 기억).
- **글자·색**: 창 오른쪽 위 '글자' 단추 → 막대로 글자 크기(0.9~1.6배), 기본·고대비·어두움 단추로 색. 이 맥에만 저장되고 설정 파일은 바뀌지 않는다. 교수님께는 1.2~1.3배를 먼저 권해 본다.
- 'Members' 탭 = 연구원 현황판(진행 프로젝트 · 다음 GRM · Milestone meeting 날짜 + '예시' 열).
- 학회 줄의 '관심' 은 학생이 누르는 것 — 누른 사람 이니셜이 학회 아래에 보인다.

## 4. 교수님께 설명드릴 때 — 실제와 예시 (사용 안내의 표와 같다)
| 구분 | 화면에서 보이는 것 | 자료 출처 | 상태 |
|---|---|---|---|
| 실제 | 오늘·이번 주 일정, 마감 남은 시간 | 구글 캘린더(CSNL·SLab) · Notion Schedule & Events | 동작 |
| 실제 | GRM 발표 순번, 회의록 초안, Paper Blitz 기록 | Notion GRM Schedule · Meeting Notes(녹취 요약) · Paper Blitz Archive(공용 저장소 덱) | 동작, 매주 자동 정리 |
| 실제 | 그랜트·학회 마감, 리마인더 | 공용 저장소 일정 파일 · Notion Conferences · 리마인더 파일 | 동작 |
| 실제 | 학회 '관심' 표시 | 공용 저장소 `Grant/_ssot/conference_interest.json` (학생이 누른 기록) | 동작 |
| 실제 | 오늘의 실험(Prolific) | Prolific | 진행 중·준비 중인 연구만, 이 맥에 연결 열쇠가 있을 때(없으면 '미연결') |
| 실제 | Milestone meeting 날짜 | 공용 저장소 `MM/<이니셜>/` 최신 파일 | 동작 — 이름에 날짜가 없으면 '수정일' 로 표시 |
| 실제 | 연구실에서 만든 앱 카드 | 앱 목록 파일 | 동작 |
| 예시 | 연구원별 프로젝트 이름(멤버 칩) | 공용 저장소 Memory/<이니셜> 폴더 이름 | 예시 — 폴더 이름만, 내용은 아직 |
| 예시 | GitHub 링크·활동 | 링크 목록 파일 | 예시 — 링크만, 활동 집계는 연결 전 |
| 예시 | 논문 추천 티어 | Notion 논문 추천(6.1 이후 새 추천 없음) | 예시 — 입력 방식 결정 뒤 재가동 |
| 예시 | 연구원별 활동 현황판(Claude 사용량 · GitHub push · 논문 추천 반응) | 표본 숫자 | 예시 — 'Members' 탭, 열마다 '예시' 칩·표 위 띠 |

한 줄 요약: **일정·마감·GRM·회의록·Paper Blitz·그랜트·학회·관심 표시·Prolific·Milestone 날짜는 실제 자료**이고, **사람별 활동 현황은 앞으로 채울 자리를 예시로 보여 드리는 것**이다.
