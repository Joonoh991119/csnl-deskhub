DeskHub 간단 안내

연구실 대시보드 · 1.0.2 · 2026년 10월 27일 · 절 제목을 누르면 펼쳐집니다

DeskHub 는 맥에서 보통 앱 창으로 여는 연구실 현황판입니다(예전처럼 바탕화면에 깔아 둘 수도 있습니다). 일정·마감·GRM(매주 연구실 미팅) 발표 순번·회의록·Paper Blitz(매주 논문 소개)·그랜트·학회 마감이 자동으로 갱신됩니다. 일정·회의록·논문을 눌러도 자료가 바뀌지 않습니다. 바뀌는 것은 학회 '관심' 체크, 논문 반응·댓글·'같이 읽자', 리마인더(등록·끝남·아님·미루기), 미팅 후속 체크(끝남·확정·아님·직접 적기)이며 대부분 6초 안에 되돌릴 수 있습니다. 학회 '관심'·'같이 읽자'와 리마인더 끝남·아님·미루기는 6초 되돌리기가 있고, 리마인더 등록은 누르는 즉시 연구실 공용 저장소에 남습니다. 논문 반응은 한 번 더 누르면 취소되며(Notion 에 취소 기록이 남음), 댓글은 보내는 즉시 남습니다.

1.0.1·1.0.2 에서 바뀐 것
  • 챗봇이 이 맥 안의 모델로도 답합니다 — 연구실 공용 연결(OpenRouter 키)이 없는 동안에는, 이 맥에 Ollama 가 켜져 있으면 그 모델(기본 qwen3:8b)에 물어 답을 지어 줍니다. 질문과 자료 조각이 맥 밖으로 나가지 않습니다. 준비는 한 번뿐입니다 — ollama.com/download 에서 Ollama 를 설치해 켜 두고, 터미널에 ollama pull qwen3:8b(약 5GB, 한 번만). 그 뒤 챗봇 창을 열면 위에 '모델 연결됨 · 로컬 qwen3:8b' 가 보입니다. 첫 답은 모델을 메모리에 올리느라 수십 초 걸릴 수 있고, 메모리 8GB 맥은 느립니다. 공용 연결이 생기면 그쪽이 먼저이고, 둘 다 없으면 예전처럼 '모델 연결 전' 으로 찾은 자료 제목만 보여 줍니다. 챗봇 창 아래 '설정' 에서 로컬 모델 이름을 바꿀 수 있습니다. (1.0.2: 1.0.1 은 로컬 모델이 생각만 하다 빈 답을 내던 것을 고쳤습니다 — 1.0.1 을 받은 맥은 한 번 더 '새 버전 받기'.)
  • 받는 법 — 이미 설치한 맥은 메뉴 막대 아이콘을 오른쪽 클릭 → '새 버전 받기'. 저장소 없이 받을 때 파일 이름은 DeskHub-1.0.2.zip 입니다.

  • 새 첫 화면 Main — 창을 열면 Main 이 먼저 보입니다. 왼쪽에는 큰 시계와 오늘 남은 일정(캘린더 · 내 수업 · 일주일 안에 닫히는 학회 초록 마감)이 있고, 그 아래 앞으로 6회의 랩미팅 발표 순번이 보입니다. 내 차례는 진하게 표시됩니다. 오른쪽 위에는 가장 가까운 학회까지 남은 날이 크게, 오른쪽 아래에는 오늘의 논문 3편이 보입니다. 새 추천이 없는 동안에는 지난 추천 가운데 3편이 날마다 바뀌어 나옵니다.
  • 위 탭 줄과 '더 보기' — 창 맨 위 탭 줄에서 Main · 일정 · GRM/Blitz · 실험/장비 · Members · 연구 · 시간표(달력 아이콘)를 한 번에 고릅니다. 일정 탭은 왼쪽에 오늘 캘린더, 가운데 학회, 오른쪽에 연구비 일정과 과제 기간을 보여 줍니다. GRM/Blitz 탭은 발표 순번·일정과 지난 Paper Blitz 를, 실험/장비 탭은 오늘의 실험과 장비 예약 표(늘 펼침)를 보여 줍니다. 예전 화면(Dashboard · Tower · Pipeline · Board 등)은 '더 보기' 에 그대로 있고, 고른 탭은 이 맥이 기억합니다.
  • 보통 앱 창 — DeskHub 가 다른 앱처럼 제목 막대가 있는 창으로 뜹니다. 왼쪽 위 단추로 닫기 · 최소화 · 확대를 하고, 전체 화면(⌃ ⌘ F)도 됩니다. Dock 과 ⌘ Tab 에 보이고, 창을 닫아도 메뉴 막대 아이콘은 남아 Dock 아이콘을 누르면 다시 열립니다. ⌃ ⌥ D 는 창이 앞에 있으면 가리고, 뒤에 있으면 앞으로 가져옵니다. 창 크기와 위치는 이 맥이 기억합니다. 예전처럼 바탕화면에 까는 방식은 메뉴 막대 아이콘 → '바탕화면 패널 모드 (예전 방식)' 에서 켭니다.
  • 글자 1.5배가 기본 — 처음 켜면 글자가 1.5배입니다. Display 판에서 0.9~2.0배로 조절하고, 판의 단추는 누르기 쉽게 커졌습니다. 이미 크기를 골라 둔 맥은 그 값 그대로입니다.
  • 논문 '커뮤니티' 창 — Main 의 논문 카드에서 '커뮤니티' 나 제목을 누르면 그 논문 창이 열립니다. 요약, 추천 이유, 읽겠음 · 읽었음 단추, 댓글 목록과 입력 칸이 있습니다. 창을 열 때와 10분마다 새로 읽습니다. 반응은 한 번 더 누르면 취소되고(취소 기록이 남음), 댓글은 보내는 즉시 남아 지울 수 없습니다.
  • 챗봇 쓰는 법 — Main 오른쪽 아래 둥근 얼굴 단추(또는 메뉴 막대 아이콘 → '챗봇 열기')를 누르고 질문을 한 줄 적습니다. '다음 GRM 발표자' · '장비 예약 방법' 두 예시 단추는 바로 답합니다. 그 밖의 질문은 연구실 자료(위키 문서와 대시보드가 읽어 둔 일정 · 학회 · 장비 · 논문)에서 관련 조각을 찾아 짧게 답하고, 근거를 펼쳐 볼 수 있습니다. 창 위에 '모델 연결 전' 이 보이면 아직 답을 지어 주는 연결이 없어 찾은 자료 제목만 보여 줍니다. 대화는 저장되지 않습니다.
  • 받는 법 — 이미 설치한 맥은 메뉴 막대 아이콘을 오른쪽 클릭 → '새 버전 받기'. 처음 설치하거나 위 메뉴가 없으면 아래 설치 절의 명령을 그대로 씁니다. 저장소 없이 받을 때 파일 이름은 DeskHub-1.0.0.zip 입니다.

증상해결
설치는 됐는데 켜지지 않음, "Bad CPU type"0.36.0 이전 판은 Intel 맥에서 안 켜집니다. 위 설치 명령을 다시 실행하면 최신 판(1.0.2, 범용)으로 바뀝니다.
메뉴 막대에 아이콘이 없음터미널에 open -a DeskHub. 그래도 없으면 설치 명령을 다시 실행합니다.
대시보드가 안 보임창을 닫았거나 가린 것입니다. Dock 의 DeskHub 아이콘을 누르거나 ⌃ ⌥ D 를 누르면 앞으로 옵니다. 바탕화면 패널 모드에서는 다른 창 뒤 바탕화면 층에 있으니 ⌃ ⌥ D 로 올립니다.
카드가 비어 있음Notion 연결 열쇠가 없거나 공용 저장소가 안 붙은 것입니다. zsh /Volumes/CSNL_new/Grant/_ssot/deskhub/setup_env.sh 이니셜 로 열쇠를 넣고, Finder → 이동 → 서버에 연결 → smb://147.47.70.15/CSNL_new.
미팅 후속에 '?' 가 보임, 체크 단추가 잠김연구실 공용 저장소(NAS)를 읽지 못한 것입니다. Finder → 이동 → 서버에 연결 → smb://147.47.70.15/CSNL_new 로 다시 연결하면 다음 갱신(10분 안)이나 r 키로 돌아옵니다. 체크한 기록은 지워지지 않습니다.
Classes 카드가 '학기 밖' 한 줄오늘이 등록된 학기 기간 밖입니다(방학). 학기가 시작되면 저절로 펼쳐집니다.
